# can-va

Cerulean Aviation Network 的虚拟航司站点，`va.ceruleanavi.net`。

成员在这里浏览和加入航司、申请成立航司、管理设置、枢纽、成员、角色、等级与累计机型资格。
机队支持购买、租赁、出售、退租、付费调机与涂装；航线支持机型限制与停用。
飞行支持计划、自由与指派调机预订、取消、UTC 飞行报告及独立审核。
个人页提供飞行历史、跳座、免费返回、钱包流水、档案、成就与 UTC 月榜。
ACARS 录制证据在本人报告及有权审核人的报告详情中显示；轨迹使用无外部底图的 SVG。
“我的飞行”提供分页的本人录制索引、UTC 到期时间与需登录的 NDJSON 流式下载。
航司概况按权限显示待审报告数量、最早待审时间与负余额重整期限。
数据全部来自 can-va-api；本站不持有任何凭据。所有界面提供简中、繁中、英语与日语。

```bash
GITHUB_TOKEN="$(gh auth token)" bun install
cp .env.example .env
bun run dev          # http://localhost:4330
bun run lint && bun run build && bun run check:pages
```

维护说明见 `AGENTS.md`。

## 开发与发布

can-ui 使用可重现的固定依赖；升级时同时更新 `package.json` 与 `bun.lock`。
先部署本站与管理端页面，再发布包含对应页面注册表的 can-ui，并升级各消费者。
先部署完整 can-va-api 与迁移，再部署本站；不得把 staff 或 internal 路由加入成员代理。
提交飞行报告会立即移动飞行员和飞机，结算须由另一位有权成员审核。
预订只在网站创建；独立 can-va-client 读取现有预订，上传轨迹后仍须由飞行员明确提交报告。
客户端证据不是飞行真实性的保证；手工值、遥测缺失与异常标记均供独立审核参考，不自动记入成绩。
已完成原始轨迹保留 90 天，未完成或放弃的录制按 30 天未活动期限清理；报告摘要与标记保留。
个人数据导出只含本人的录制元数据与需登录的下载索引，不内嵌原始轨迹，也不包含被本人审核的他人轨迹。
金额为整数最小单位；页面显示 credits，所有日期时间均为 UTC。
